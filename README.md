# 🚀 Featured Projects

## 👆 Swipe — AI-Powered Job Discovery

A Tinder-style job discovery platform with AI-driven matching. Uses Google Gemini embeddings + pgvector for semantic similarity search, swipe gesture animations, and a full data pipeline for LinkedIn job scraping.

**Features:** Swipe-based discovery, AI resume parsing (Gemini, 5-model fallback chain), pgvector cosine similarity ranking, Google OAuth + Phone OTP auth, daily swipe limits, cursor-based pagination, LinkedIn job scraper via Apify, dark mode UI with custom typography.

**Tech Stack:** `React Native` `Expo` `Node.js` `Express` `PostgreSQL` `pgvector` `Google Gemini` `Python` `Docker`
